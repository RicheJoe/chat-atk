# 需求说明

商标注册流程客服。使用者是准备申请商标、想先弄清流程的人，不是审查员，也不是代理机构内部人员。

## 要演示的三条路径

1. 简单问答。例如「商标注册大概要多久」「一类大概多少钱」「个体户能申请吗」。回答要带资料标题或工具来源，费用和期限要带摘录日期。
2. 办事引导。用户只说「我想注册一个商标」时，按申请人类型、商标名称、商品或服务、是否已有图样这个顺序追问。信息够了再给出候选类别、材料清单和官费。
3. 边界。用户问某个名字和某个品牌像不像、能不能过审时，说明不能代替商标局作审查结论，不给通过率，也不判断是否侵权。

现场话术在 `docs/演示话术.md`。输入框上方有这三条路径里的推荐问题。界面固定显示：本对话是商标注册流程咨询，不构成法律意见。

## 不做什么

- 不咨询专利、版权和诉讼。
- 不判断能否注册、是否相同或近似、是否侵权。
- 不报规费清单以外的金额，不含代理费。
- 不做知识库后台。资料用带来源和日期的 Markdown。
- 不把桌面端重写成 Java。Java、MySQL、Redis、Docker 只在方案里对照现有链路，等明确后再做。
