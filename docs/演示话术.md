# 演示话术

按下面三条路径现场提问。新对话才会带上「流程咨询、不是律师」和「结论、依据、下一步」这套提示。推荐问题已经放在输入框上方。

## 简单问答

1. 商标注册大概要多久。依据应是「商标注册的审查和核准 / 从申请到发证的顺序」。要说明九个月审查、公告后二个月异议，并写明这些期限自 2027-01-01 起施行，在此之前不要说成现行有效。
2. 一类大概多少钱。必须出现「已查询：费用」。网上申请 270 元，纸质申请 300 元，两个都说。来源标题是「规费清单」，更新日期 2026-09-28。不要报代理费。
3. 个体户能申请吗。应查询材料清单，申请人类型是国内自然人，材料里有申请书、图样、个体工商户营业执照复印件和身份证明。
4. 驳回通知送达后多久可以复审。依据是「驳回之后怎么办」，期限是十五日，并带上施行日期。

## 办事引导

5. 我想注册一个商标。先问申请人类型，不要同时把类别、材料和费用都报出来。
6. 我是个体户。接着问商标名称。
7. 名字叫晴川，卖衣服，图样还没有。这时再查询候选类别、材料清单和费用：第二十五类、国内自然人材料、网上 270 元和纸质 300 元。
8. 我卖食品。不要直接报第三十类，先问是饮料、米面、调味品还是乳制品。
9. 我们公司要注册一个做软件的商标。类别候选是第九类，材料按国内法人，申请书要加盖公章。

## 边界

10. 这个名字和某某大牌像不像，能不能过审。拒绝给出能否注册或是否近似的结论，依据是「客服不能判断能否注册或是否近似」。
11. 帮我算一下通过率。说明资料里没有通过率，不能估算。
12. 这个商标会不会侵权。说明这是流程咨询，不是律师意见，不能判断侵权。
